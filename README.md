# QuickRead

Быстрое чтение по одному слову (RSVP): слова появляются в одной точке, с красной опорной буквой, и глазам не нужно бегать по строкам.

**Открыть:** https://sergeykorzikov.github.io/quickread/

- Работает в браузере на телефоне и компьютере, после первого открытия — без интернета.
- Открывает txt, md, pdf (с текстовым слоем), docx, epub, fb2, html; читает из буфера обмена.
- Умные паузы на знаках препинания и абзацах, 100–1500 слов в минуту, 1–3 слова за раз.
- Запоминает книгу и место, где вы остановились.

**iPhone и iPad:** откройте ссылку в Safari → «Поделиться» → «На экран „Домой“» → «Добавить».

Клавиши на компьютере: пробел — старт/пауза, ← → — по словам, Shift + ← → — по предложениям, ↑ ↓ — скорость, ⌘E — текст, ⌘O — открыть файл, ⇧⌘V — читать из буфера.
